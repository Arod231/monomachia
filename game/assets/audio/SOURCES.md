# Audio sources

Where every sound in `game/assets/audio/` comes from and how it was made. This file is written by the audio scripts; edit the scripts, not this file.

| Folder | Made by | Command |
|---|---|---|
| `sfx/` (all but `gen_*`) | cut and processed from the Sonniss bundle | `npm run audio:sonniss` (`scripts/audio/extract-sonniss.mjs`, picks in `scripts/audio/sonniss-picks.json`) |
| `sfx/gen_*` | synthesized | `npm run audio:synth` (`scripts/audio/synth.mjs`) |
| `music/` | generated placeholder music | `npm run audio:music` (`scripts/audio/music.mjs`) |

All files are 16-bit PCM WAV at 44.1 kHz. Effects are mono unless noted; the ambience loop and the music are stereo and carry their loop points in a `smpl` chunk, which Godot reads as the loop.

## Variation pools

The sound bank (`game/audio/sound_bank.gd`) plays one variation of a pool at random each time. So that none jumps out, every file in a pool is matched on short-term loudness (the RMS level of its loudest 100 ms) under a peak ceiling: by gain and, where a variation cannot reach the pool's level under the ceiling, a fast peak limiter (`scripts/audio/lib/pools.mjs`; the extractor and the synthesizer log the gain and any limiting).
